## Executive Summary

**There is no double-counting bug.** The two numbers reflect different counting conventions, both scientifically valid. The reconciled canonical independent event count is **707** for 2015-2024 across 5 regions.

## Counting Definitions

| Term | Definition | Used In |
|---|---|---|
| **POT-only** | Coles (2001) q95 threshold + 168h gap declustering. No TC dedup. | LATEST_PROGRESS.md |
| **POT+TC deduped** | POT clusters + canonical TCs, with TCs that coincide with POT clusters counted ONCE. | INDEPENDENT_TEST_FEASIBILITY.md, STATISTICAL BOOTSTRAP |
| **Canonical Independent Unit** | POT cluster that does NOT correspond to a known TC OR a canonical TC track. Used for all hypothesis testing. | Wave 2.0+ formal inference |

## WAVE 2.7 CORRECTION (2026-11-05) — supersedes the 707 figure above

Re-derivation from raw manifests (`data/manifests/multiyear_declustering.json`) with
explicit one-to-one overlap matching (`src/tidetail/event_union.py`,
`scripts/event_set_audit.py`, `tests/test_event_set_arithmetic.py`) gives:

| Quantity | Value |
|---|---:|
| POT clusters, 2015-2024 | 634 |
| Canonical TCs, 2015-2024 | 73 |
| One-to-one matches (168 h window) | **28** |
| POT-only | 606 |
| TC-only | 45 |
| **Union** | **679** |

The Wave 2.5 statement "every canonical TC generates a POT cluster (overlap = 73)" is
**false**: only 28 of 73 TCs coincide with a POT cluster. The arithmetic
`634 + 73 - 73 = 707` therefore subtracted an overlap that was never measured.
The correct decade-level independent-event union is **679**, not 707 and not 634.

Per-region 2015-2024 unions: ny_bight 178, us_gulf_coast 138,
south_atlantic_charleston 143, southeast_australia 101, thames_north_sea 119.

2024 cohort unions (strict 168 h): ny 15, gulf 15, charleston 14, se_aus 6, thames 10
= **60**; the bootstrap-observed extreme-unit count is **59** because one Thames
cluster has no test windows in the 2024 split. This is a cohort effect, not a
duplicated event.

Tolerance sensitivity (0/24/48/72 h) and full per-region tables are in
`data/results/wave27_event_set_audit.json`. The union identity
(`union = POT + TC-only = POT-only + TC`) is asserted for every region and period.
