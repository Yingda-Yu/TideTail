\section{Discussion}
\label{sec:discussion}

\subsection{The DDPM residual amplification mechanism is fundamental, not budgetary}
Our 50-epoch full-budget retraining definitively rules out ``insufficient
training'' as an explanation for the M2 failure. Across 5 regions $\times$ 2
seeds $\times$ 50 epochs: scale ratios of 0.11--0.35 (all below the 0.5 gate
threshold), peak ratios of 2.8--26.4$\times$ (all above the 2.5 upper bound),
and one NaN gradient collapse at epoch 31 on the high-variance thames region.

The failure mechanism is architectural. The cosine1000-subsample schedule fixes
the terminal $\bar{\alpha}_T$ from $5.93 \times 10^{-7}$ (1299$\times$
amplification) to $5.89 \times 10^{-4}$ (41$\times$ amplification). This is
a 30$\times$ reduction, but 41$\times$ amplification is still enough that the
reverse chain's accumulated epsilon-prediction error gets amplified into
physically implausible residuals. Increasing training budget from 3 to 50
epochs improved mean scale ratio from 0.11 to 0.18 — a 64\% relative
improvement, still 3$\times$ below the 0.5 gate threshold.

The critical insight is that this finding applies specifically to \emph{DDPM
operating on residual components after trend/seasonal decomposition}. The
decomposition isolates the residual as a small-variance sub-space where
amplification is fatal. A DDPM operating directly on full water level (not
decomposed) may behave differently; the decomposition itself may be the
problem, not DDPM in general.

\subsection{Why Flow Matching avoids this failure}
Flow Matching (CNF) fundamentally avoids reverse-chain accumulation by
construction. The single velocity-regression loss trains a field that
transports samples from a simple Gaussian prior to the data distribution via
straight-line interpolation, and inference integrates the learned ODE
\emph{forward} in time (Euler, 64 steps). There is no per-step amplification
and no accumulated error chain.

The architectural control is close: both models use dilated TCN encoders with
similar parameter budgets (M4: 27,937 vs M2: 39,425), train on the same data
with the same per-sample residual normalization, and forecast 72 hours. The
only differences are (a) the generative framework (CNF vs DDPM) and (b) the
residual-decomposition wrapper that M2 uses. The result — M4 passes all
scale gates while M2 fails catastrophically — is therefore attributable to
the generative framework choice, not model capacity or data protocol.

M4 is not perfect: peak KS-test $p$-values are uniformly below 0.01
(distribution mismatch in peak magnitudes, expected from any single generative
model), and near-duplicate ratios approach 1.0 on thames/australia (mode
collapse, known limitation of single-flow CNF). But scale is correct,
Wasserstein-1 distances are $\leq$0.10, and q95/q99 quantiles match within
3\% of real values. These are solvable with more sophisticated generative
strategies (mixture models, diverse sampling); the DDPM issue is not.

\subsection{Data and protocol limitations}
\begin{itemize}
    \item \textbf{IBTrACS storm data unavailable}. NCEI restructured the
    IBTrACS download URLs; all tested URLs return HTTP 404. An alternative
    mirror (\texttt{ibtracs.unca.edu}) may provide CSV downloads but was not
    verified before this draft. HURDAT2 (2004 storms, 7.1 MB, SHA256 verified)
    provides partial coverage.

    \item \textbf{Real-world gauges downloaded but not integrated}. NOAA
    CO-OPS 3 verified stations provide 360 monthly CSVs (102 MB, 2.6M rows,
    6-min resolution). These are held-out ground-truth that can validate
    model forecasts against observed storms, but were not used in the current
    generative experiments which use prime-formal synthetic targets.

    \item \textbf{Canonical independent storm grouping is not yet signed}.
    Current threshold-run event intervals are not meteorologically independent
    storms. The HK boundary-crossing event is unresolved.

    \item \textbf{License and vertical datum sign-off are incomplete} for the
    Hong Kong region and upstream data provenance of other regions.
\end{itemize}

\subsection{Augmentation utility not yet evaluated}
The A3 Flow Matching synthetic augmentation experiment (Section A3) evaluates
whether adding Flow-Matching-generated residual targets to GRU/TCN training
sets improves tail forecasting accuracy. Five augment groups (A0 real-only,
A1 extreme oversampling, A2 physics residual noise, A3 FM synthetic at
10\%/25\%/50\% ratios) run across 5 regions $\times$ 2 seeds for 30 epochs
each. Results are pending final execution on GPU 4.

\subsection{What this \emph{is}}
Despite containing a clear negative result, this work provides:
\begin{enumerate}
    \item A fully documented and leakage-safe research protocol frozen at the
    96$\rightarrow$72 contract with train-only scalers and chronological 8:1:1 splits.
    \item A definitive diagnosis of \emph{DDPM residual-decomposition
    amplification} as an architectural failure mode for tidal surge
    generation, confirmed across 10 full-budget runs.
    \item A generative architecture comparison (CNF vs DDPM) with matched
    architectural controls and empirical evidence that Flow Matching is the
    viable generative approach for this task.
    \item Reproducible data download manifest with SHA256 hashes for real
    NOAA/HURDAT2 sources.
    \item 153 passing pytest tests and ruff-clean code as PR gate.
\end{enumerate}
