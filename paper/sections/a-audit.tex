\label{sec:audit}

This appendix records the traceable evidence basis for the factual claims in this
paper. Each entry names the artifact, the producing command, and the test that
guards it. Nothing in the main text is asserted without a row here.

\subsection{Known discrepancies retained}

Two discrepancies are recorded rather than resolved, because resolving them
would require re-running experiments that the evidence already disqualifies.

\begin{enumerate}
    \item \textbf{The 707 event count.} Wave 2.5/2.6 documents added POT and TC
    totals without computing the intersection. The corrected union is 679. The
    old number appears in superseded audit files, which are annotated, not
    deleted, so that the error remains traceable.
    \item \textbf{The Diffusion-TS target.} The production Diffusion-TS run
    consumes observed total water level by design (its decomposition is defined
    on the full signal, enforced by
    \texttt{test\_train\_generative\_model\_loader\_patches\_total\_water}),
    whereas the other generators consume the residual. Its row in
    Table~\ref{tab:generators} is therefore scored against its own target and is
    not ranked against the other generators. This is a comparability limit, not
    a defect.
\end{enumerate}
